# pokesleep-ingredient-planner — ねむりの食材手帳

ポケモンスリープの食材担当と厳選状況を手入力で管理する、スマートフォン対応の非公式Webアプリです。

## 機能

- 個体の登録・編集、食材3枠、性格、サブスキル、手動の厳選完了
- 現在／50／60／70／80の表示切り替え（現在レベルを下げない）
- 条件を明記した通常おてつだい24時間の食材期待値
- 選択した料理3食分と各主担当の出力の比較
- シェア画像の作成・保存、JSONバックアップの書き出し・読み込み

Lv.80は将来の解放表示のみで数値を出しません。計算情報が不足した個体や未対応の特殊種族も推定値を出しません。スクショ読み取りは将来機能です。

## ローカルで起動

Python 3をインストールした環境で、このフォルダーから次を実行します。

```sh
python3 launch.py
```

Macでは `起動.command` を開いても起動できます。ブラウザーで http://127.0.0.1:8765/ を開きます。ビルドやAPIキーは不要です。

## GitHub Pagesで公開

公開URL：https://mokuhibi.github.io/pokesleep-ingredient-planner/

2026-10-01より公開リポジトリと無料のGitHub Pagesを使用します。アプリ利用のログインは不要です。

リポジトリ名は `pokesleep-ingredient-planner`、ブランチは `main` を使用します。Settings → Pages → Build and deploymentで **GitHub Actions** を選び、Publish GitHub Pagesを実行します。公開URLは成功したActionsのdeployment出力とSettings → Pagesで確認できます。

リポジトリのコードとGit履歴、Pagesの画面・JavaScript・共通データは公開されます。登録した個体情報は含まれません。コミットには個人のメールアドレスではなくGitHubのnoreply形式を使用します。有料契約は不要です。

公開時は必要なHTML/CSS/JavaScriptとライセンスだけを許可リスト方式で配信します。個体データ、バックアップ、スクショ、認証情報を追加しないでください。

## 保存・端末移行

個体情報はアクセス元のブラウザーのlocalStorageに保存し、サーバーへ送信しません。アクセス解析や外部API呼び出しもありません。通常モードで同じURLを再度開けば保存内容を読み込みます。プライベートブラウズ、サイトデータ削除、端末の保存領域整理では消えることがあるため、定期的にバックアップしてください。

「保存・復元」からJSONを書き出し、別端末で読み込みます。ローカル版とPages版、別ブラウザーの間も同じ方法で移行できます。バックアップは個体情報を含むため、GitHubにアップロードしないでください。GitHub Pagesは同じホスト名内の別プロジェクトと保存領域を共有するため、同じアカウントのPagesには信頼できるコードだけを配置してください。

画像は「画像でシェア」から作成し、保存リンク、または画像の長押しで保存します。外部への投稿は自動で行いません。

## 計算・出典・テスト

初期条件はげんき100一定、24時間、所持数が満杯になる前に回収です。本人の補正を反映し、他個体の補助・メインスキル・イベント等は含めません。実際の同時編成で3食作れる保証ではありません。

Neroli’s Labの採用版・個別更新日・出典は「条件とデータ」に記録しています。第三者ライセンスは `licenses/` に同梱しています。

```sh
node tests/core.test.cjs
```

画面表示は `app.js`、計算は `core.js`、共通データは `data.js` です。仕様は `SPEC.md`、開発方針は `AGENTS.md` を参照してください。

## 一覧の表示

「省スペース」は食材別の特徴一覧、「情報多め」は個体別の詳細比較です。最後の表示はこのブラウザーに保存します。「19食材を1枚に」で全食材を1枚の画像にまとめられます。基本形の表示画像はPokeAPI/sprites由来で、フォーム違いは名前で区別します。画像も同じサイトから配信し、個体情報を外部画像サービスに送りません。出典・採用版は assets/pokemon/SOURCE.md、ライセンスは licenses/PokeAPI-sprites.txt を参照してください。
